# Generative AI Engineering Journey 🚀

A hands-on learning journey focused on building a strong foundation in **Python, APIs, and Large Language Models (LLMs)** as the first step toward becoming a Generative AI Engineer.

This repository documents my progress, notes, coding exercises, and practical projects throughout the learning journey.

## 🎯 First Two Weeks: Learning Roadmap

**Duration:** 2 Weeks  
**Study Schedule:** 5 Days per Week  
**Daily Commitment:** 3 Hours  
**Total Learning Time:** 30 Hours

---

## 📅 Week 1 — Python Foundations for AI

### Goal
Strengthen Python fundamentals and learn how to write organized, reusable code while handling files and structured data.

### Topics Covered

| Day | Topics |
|---|---|
| Day 1 | Functions, Variables, Data Types, Arguments, Return Values, Scope |
| Day 2 | Conditions, Loops, Boolean Logic, Debugging |
| Day 3 | Data Structures: Lists, Tuples, Sets, Dictionaries |
| Day 4 | File Handling, JSON, Exception Handling |
| Day 5 | OOP, Classes, Objects, Virtual Environments, Git |

### Practical Exercises
- Create reusable Python functions.
- Build a Number Guessing Game.
- Practice working with Lists and Dictionaries.
- Read and write TXT and JSON files.
- Handle exceptions and invalid inputs.
- Practice OOP using classes and objects.

### 🛠️ Week 1 Project: Text Processing Tool

Build a Python application that reads and analyzes text files.

**Requirements:**
- Read a `.txt` file provided by the user.
- Clean the text by removing unnecessary spaces.
- Count the total number of words and sentences.
- Identify the 10 most frequent words.
- Save the analysis results in a JSON file.
- Handle missing and empty files.

**Expected Deliverables:**
- Python source code.
- Organized functions and classes.
- Error handling.
- Project README documentation.

---

## 📅 Week 2 — APIs, Data Handling & LLM Fundamentals

### Goal
Understand how Python communicates with web APIs, learn the fundamentals of LLMs, and make the first real API call to a language model.

### Topics Covered

| Day | Topics |
|---|---|
| Day 1 | HTTP, REST APIs, Requests, GET, POST, Status Codes |
| Day 2 | JSON Structure, Parsing, Serialization, API Error Handling |
| Day 3 | Generative AI, LLMs, Transformers, Tokens, Tokenization, Context Window, Temperature |
| Day 4 | API Keys, Python SDK, Client Initialization, Sending Inputs, Receiving Outputs |
| Day 5 | Mini Project: AI Text Summarizer |

### Practical Exercises
- Send GET and POST requests using Python.
- Fetch data from JSONPlaceholder.
- Parse and manipulate JSON responses.
- Handle API errors and timeouts.
- Explore tokenization using an LLM tokenizer.
- Understand the difference between AI, ML, Deep Learning, and LLMs.
- Make the first API call to an LLM.

### 🛠️ Week 2 Project: AI Text Summarizer

Build a Python application that uses an LLM API to summarize user-provided text.

**Requirements:**
- Accept text input from the user.
- Validate that the input is not empty.
- Send the text to an LLM.
- Generate a clear and concise summary.
- Display the generated summary.
- Save the result as a TXT or JSON file.
- Handle API and connection errors.

**Additional Improvements:**
- Short Summary.
- Detailed Summary.
- Bullet Points Summary.

## 📌 Learning Guidelines

- Focus on one main instructor or course for each topic.
- Spend no more than one hour daily watching videos.
- Reproduce code independently instead of copying it.
- Read official documentation alongside tutorials.
- Understand errors before searching for solutions.
- Push completed exercises and projects to GitHub.
- Do not move to the next week until the main project works.

---

**The main goal is not just to finish tutorials, but to build practical projects and understand the concepts well enough to implement them independently.** 🚀
