# Week 1 — Python Foundations for AI 🐍

## 🎯 Learning Objectives

Build a strong foundation in Python by practicing functions, control flow, data structures, file handling, exception handling, and Object-Oriented Programming (OOP).

**Duration:** 5 Days  
**Study Time:** 3 Hours per Day  
**Total:** 15 Hours

## 📅 Daily Learning Plan

### Day 1 — Functions & Variables
**Topics:**
- Variables and Data Types
- Functions
- Arguments and Return Values
- Scope
- Debugging

**Learning Resources:**
- CS50P — Lecture 0: Functions, Variables
- Python Official Documentation

**Practice:**
- Write a function that returns a welcome message.
- Create a function that adds two numbers.
- Find the largest number in a list.
- Count the words in a sentence.
- Calculate the average of a list of grades.

**Daily Challenge:** Write five functions independently without copying code.

### Day 2 — Conditions, Loops & Logic
**Topics:**
- if / elif / else
- Boolean Logic
- for and while loops
- break and continue
- range()
- Nested Loops

**Learning Resources:**
- CS50P — Lecture 1: Conditionals
- CS50P — Lecture 2: Loops
- Python Control Flow Documentation

**Practice:**
- Check whether a number is even or odd.
- Find the largest of three numbers.
- Print numbers from 1 to 100.
- Print even numbers only.
- Create a multiplication table.

**Daily Challenge:** Build a Number Guessing Game with only five attempts.

### Day 3 — Data Structures
**Topics:**
- Lists, Tuples, and Sets
- Dictionaries
- List Methods
- Dictionary Keys and Values
- Nested Data Structures
- List Comprehension

**Learning Resources:**
- Corey Schafer — Python Beginner Tutorials
- Python Data Structures Documentation

**Practice:**
- Create a list containing ten numbers.
- Find the maximum and minimum values.
- Remove duplicates using a Set.
- Create a dictionary representing a student.
- Store five students using a List of Dictionaries.
- Count word occurrences in a sentence.

**Daily Challenge:** Build a simple Student Management System using Lists and Dictionaries.

### Day 4 — Files, JSON & Exception Handling
**Topics:**
- File Handling
- open(), read(), and write()
- with Statement
- JSON Load and Dump
- try and except
- Custom Exceptions

**Learning Resources:**
- CS50P — Lecture 3: Exceptions
- CS50P — Lecture 7: File I/O
- Corey Schafer — File Objects
- Python Official Documentation

**Practice:**
- Create and write to a TXT file.
- Read file contents using Python.
- Save student data in JSON format.
- Convert JSON data into a Dictionary.
- Handle FileNotFoundError.
- Handle invalid JSON data.

**Daily Challenge:** Build a Notes application that saves user notes in a JSON file and displays them again.

### Day 5 — OOP, Virtual Environments & Mini Project
**Topics:**
- Classes and Objects
- Constructors (__init__)
- Instance Attributes
- Methods
- Modules and Imports
- pip and venv
- Git Commit and Push

**Learning Resources:**
- Corey Schafer — Python OOP: Classes and Instances
- Python Classes Documentation
- Python Virtual Environments Documentation
- Git Documentation

**Practice:**
- Create a Student class.
- Add attributes and methods.
- Create and activate a virtual environment.
- Organize code into Python modules.
- Commit and push your work to GitHub.

## 🏆 Weekly Outcome

By the end of this week, I should be able to:
- Write organized and reusable Python functions.
- Apply conditions and loops.
- Work with Python data structures.
- Read and write TXT and JSON files.
- Handle exceptions.
- Understand basic OOP concepts.
- Use virtual environments and Git.
